## Что изменено

- Все четыре секции используют один компонент карточки: размеры, типографика, кнопки и переключатели согласованы. Карточки не меняют высоту при переключении.
- Отменены искусственные большие минимальные высоты. Ширина ограничена 760 px, поля 24–32 px; на узком экране карточки растут по содержимому.
- Стеклянная шапка и согласованная пользователем палитра сохранены. Прозрачный логотип подаётся в WebP: около 49 KB вместо PNG 738 KB.
- При клике по меню заголовок, карточка и навигация центрируются в области под фиксированной шапкой. Длинный контент прокручивается без обрезания.
- Основной текст на мобильном 16 px с межстрочным интервалом 1,6. Ввод в формах 16 px, кнопки карточек высотой 48 px, стрелки 44×44 px. Длинные подписи не переносятся.
- На первом экране добавлены понятные переходы Explore Services и Contact Us; общая ссылка Read More заменена на Meet Liam Dillon.
- Анимация перемещает всю карточку, включая стеклянную поверхность и кнопку; 3D-поворот убран. Быстрые клики прерывают предыдущий переход, reduced-motion отключает движение.
- Фоны ниже первого экрана загружаются лениво через responsive img. Cloudinary отдаёт подходящий размер и современный формат.
- Главный фон загружается приоритетно с отдельными мобильным и desktop preload. Большой исходный favicon заменён размером 32 px.
- Исправлены реальные srcSet и пропорции фотографий Liam. Статический HTML гидратируется, а не создаётся заново.
- У главной и Liam отдельные title/description/canonical, Open Graph/Twitter, Organization/WebSite/WebPage/ProfilePage JSON-LD. Метаданные и JSON-LD синхронизируются при навигации внутри SPA.
- Sitemap содержит только главную и Liam. 404 не индексируется. Netlify отдаёт статическую страницу Liam и настоящие 404 для неизвестных маршрутов.
- Устранены некорректные ARIA-роли и декоративные кнопки без действий. axe: 0 нарушений на обеих страницах.
- В Netlify закреплены build command и dist; хешированные assets кешируются на год.

## Проверки

npm run lint; npm run build; npm test; Chromium/axe для обеих страниц; Lighthouse; ширины 320, 390, 768 и 1440 px. Проверены центрирование, отсутствие горизонтального переполнения, одиночный H1, canonical, доступность скрытых слайдов, локальные сценарии ошибок/успеха формы. Настоящая доставка форм зависит от настроек существующего Netlify Forms.

Страница Liam после оптимизации: Lighthouse SEO 100, Accessibility 100, Best Practices 100, Performance 97; LCP 2,2 с.

В production были отключены старые Netlify-плагины Inline Critical CSS (ошибка сборки), Sitemap (дублирующий генератор) и Cloudinary (переписывание URL через неверный аккаунт). Прямые Cloudinary-URL и оптимизированные локальные WebP остаются в исходниках. Для воспроизводимой установки оставлен package-lock.json.

## После публикации

Проверить HTML и статусы /, /liam, /sitemap.xml, /robots.txt и неизвестного URL на действующем домене. Отправить sitemap в Search Console при наличии доступа. Соцсети пока требуют реальных URL профилей; новые отзывы, цены и результаты клиентов не добавлялись без подтверждённых данных.

Источники: [Google JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [web.dev: LCP](https://web.dev/articles/optimize-lcp).
